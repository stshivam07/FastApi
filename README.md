Patient Management System

About the Project:-
A Patient Management System built using Python and FastAPI. This project provides REST APIs to manage patient records and calculate Body Mass Index (BMI).


Features :-
.Create and manage patient records
.Validate patient data using Pydantic
.Calculate BMI automatically
.Classify patients based on BMI
.Handle duplicate patient IDs


Technologies Used :-
.Python ,FastAPI ,Pydantic ,Uvicorn


Project Files :-
(a)  main4.py — Main application code
(b) requirements.txt — Required Python packages
(c) patients.json — Patient records used by the application


How to Run the Project :-

-Clone or download this repository.

-Create and activate a Python virtual environment.

-Install the dependencies:
pip install -r requirements.txt

-Start the FastAPI application:
uvicorn main4:app --reload

-Open the API documentation in your browser:
http://127.0.0.1:8000/docs


Purpose:-
This project was developed to practice Python, FastAPI, REST API development, and data validation.
